# CodeShield

JavaScript protection/obfuscation UI using the supplied `theme.html` visual language.

## Included languages/files
- HTML: `index.html`
- CSS: `style.css`
- JavaScript: `app.js`
- TypeScript: `src/types.ts`
- TSX: `src/ModeCard.tsx`
- Python: `src/encoder.py`

No language file from the original package is removed.

## Protection
- Standard wrapper
- China identifiers
- Invisible zero-width layer
- Layered encoding
- Comment stripping
- Lightweight compaction
- 200 KB / 500 KB output-size target using inert padding
- Local browser processing

## Important
This is obfuscation/encoding, not cryptographic encryption. Executable JavaScript can ultimately be inspected by a determined user. Output padding makes the file larger but does not make it impossible to rename or reverse engineer.
